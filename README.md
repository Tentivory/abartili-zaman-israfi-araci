# ⏳ ABARTILI ZAMAN İSRAFI ARACI

> *"Zaman paradır" diyenlere bilimsel bir cevap: Hayır, zaman israf edilmek için var.*

Bu repository, insanlığın en büyük sorunlarından biri olan **zaman yönetimi** problemine radikal bir çözüm sunar: Hiçbir şey yapmamak.

## 🚀 Ne Yapıyor?

`zaman_israfi.py` dosyasını çalıştırdığınızda:

1. Size kaç saniye boşa harcamak istediğinizi sorar.
2. O süre boyunca ekrana rastgele felsefi ve absürt mesajlar basar.
3. Her saniye gerçekten 1 saniye bekler. (Evet, `time.sleep(1)` kullanır. Gerçek bilim.)
4. Sonunda sizi tebrik eder çünkü hiçbir şey başarmadınız.

## 📊 Neden Bu Kadar Ciddi?

Çünkü zaman israfı artık bir hobi değil, bir **yaşam tarzı** olmalı. Bu araç, sizi o yaşam tarzına bilimsel bir şekilde sokar.

## 💻 Nasıl Kullanılır?

```bash
python zaman_israfi.py
```

Veya daha dramatik:

```bash
python3 zaman_israfi.py
```

## ⚠️ Uyarılar

- Bu program bağımlılık yapabilir.
- Üretkenliğinizi %100 düşürebilir.
- Eşiniz/aileniz "yine mi o program?" diye sorabilir.
- Gerçekten çalışır. Yalan yok.

## 🤔 Neden Yazdık?

Çünkü bazen hiçbir şey yapmamak, bir şeyler yapmaktan daha zordur. Biz o zorluğu sizin için çözdük.
